
# ufile-gosdk (Modified Version)

This repository is a customized version of the official [UCloud UFile Go SDK](https://github.com/ufilesdk-dev/ufile-gosdk).  
The main modification is a small change to the `PutFile` function to better fit specific requirements.

## Features

- Based on the official UFile Go SDK.
- Includes a minor modification to the `PutFile` function.
- Compatible with Go projects.

## Reference

For more details and official documentation, please refer to the [original UFile Go SDK](https://github.com/ufilesdk-dev/ufile-gosdk).

## Installation

```bash
go get github.com/jianfyun/ufile-gosdk
```

## Usage

> **Note:** Usage is the same as the official SDK, except for the modified `PutFile` function.

Import the package in your Go project:

```go
import "github.com/jianfyun/ufile-gosdk"
```

Refer to the [official documentation](https://github.com/ufilesdk-dev/ufile-gosdk) for detailed usage instructions.
